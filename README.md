# Прототип портала международных новостроек

Статичная вёрстка страниц на HTML и CSS, без JavaScript и сборки. Данные на страницах тестовые.
На следующем этапе разметка переносится в шаблоны Blade, классы и структура блоков сохраняются.

## Как открыть

Любой статичный сервер из корня папки, например:

```bash
python -m http.server 8766 --bind 127.0.0.1
```

Затем http://127.0.0.1:8766/html/index.html. Через `file://` страницы тоже открываются.

## Страницы

| Файл | Что показывает |
|---|---|
| `html/index.html` | Главная: первый экран, направления, выбор редакции, подход, форма подбора |
| `html/catalog.html` | Каталог с выбранной страной: фильтры, сортировка, выдача по 12, страницы |
| `html/catalog-empty.html` | Каталог, по фильтрам ничего не найдено; окно заявки на подбор с примером ошибки у поля |

Ссылки на ещё не свёрстанные страницы (`object.html`, `compare.html`, `cabinet.html`, `about.html`,
юридические) ведут в никуда, пока страницы не появятся.

## Архитектура

| Файл | За что отвечает | Чего не делает |
|---|---|---|
| `css/base.css` | переменные `:root`, сброс, типографика, контейнер, `section`, `eyebrow`, кнопки, иконки | не знает о конкретных блоках страниц |
| `css/blocks.css` | общие блоки: `header`, `hero`, `direction`, `projects`, `project-card`, `approach`, `lead-form`, `form`, `field`, `footer` | стили, нужные только каталогу |
| `css/catalog.css` | `catalog`, `filters`, `sort`, `chips`, `pagination`, `empty`, `modal` | общие блоки |
| `img/` | фото и логотип в webp | |

Правила:
- классы по БЭМ (`block__element--modifier`), один класс в селекторе, цвета и размеры только через переменные;
- раскладка на flex, grid только у сеток карточек и для наложения текста на фото (`hero`, `direction`, `project-card__media`);
- брейкпоинты 1240, 1024, 768, 480;
- без JavaScript: меню на телефоне, фильтры на планшете и телефоне и окно заявки открываются через `:target`
  (ссылка на `#menu`, `#filters`, `#podbor-modal`, закрытие ссылкой на `#`). Фильтры отправляются обычной
  GET-формой, сортировка и страницы это ссылки с параметрами. Список городов приходит с сервера уже под
  выбранную страну;
- в формах заявок первое поле `company_website` это приманка для ботов, скрыта за экраном классом `trap`.

Пока не сделано, нужно на этапе с сервером: маска телефона при выборе способа связи «Телефон», проверка
форм, отметка кнопок «В избранное» и «К сравнению».

## Внешние зависимости

- Шрифт Montserrat (OFL) подключается с Google Fonts. Если сервис недоступен, текст показывается системным
  шрифтом. Для боевого сайта шрифт лучше положить на свой сервер.
- Фото и логотип взяты с сайта hotdeals.estate того же владельца.
