# Прототип портала международных новостроек

Статичная вёрстка страниц на HTML и CSS, без сборки. Данные на страницах тестовые.
На следующем этапе разметка переносится в шаблоны Blade, классы и структура блоков сохраняются.

## Как открыть

Любой статичный сервер из корня папки, например:

```bash
python -m http.server 8766 --bind 127.0.0.1
```

Затем http://127.0.0.1:8766/html/index.html. Через `file://` страницы тоже открываются.

## Страницы

| Файл | Что показывает |
|---|---|
| `html/index.html` | Главная: первый экран с поиском, направления, выбор редакции, вопросы о подходе, форма подбора |
| `html/catalog.html` | Каталог с выбранной страной: панель фильтров сверху, сортировка, выдача по 12, страницы |
| `html/catalog-empty.html` | Каталог, по фильтрам ничего не найдено; окно заявки на подбор с примером ошибки у поля |
| `html/object.html` | Карточка объекта: галерея, основные сведения и цена в валюте застройщика с пересчётом в доллары, описание, расположение, условия оплаты, планировки, инвестиционный комментарий, источники; окна «Запросить условия» (объект подставлен) и «Получить подборку» |
| `html/about.html` | О проекте: роль портала, как отбираются проекты, как работает заявка; блок контактов `#kontakty` с реквизитами |
| `html/privacy.html`, `html/consent.html`, `html/disclaimer.html` | Юридические документы на одном шаблоне `doc`: политика обработки данных, согласие, справочная оговорка. Тексты черновые, на странице есть пометка |
| `html/404.html` | Страница не найдена, переход в каталог; закрыта от индексации |

Ссылки на ещё не свёрстанные страницы (`compare.html`, `cabinet.html`) ведут в никуда, пока страницы
не появятся. Главная и каталог пока не ссылаются на карточку объекта.

Шапка, нижняя панель с листом меню и подвал на новых страницах скопированы из `catalog.html`; правятся
во всех страницах сразу.

## Архитектура

| Файл | За что отвечает | Чего не делает |
|---|---|---|
| `css/base.css` | переменные `:root`, сброс, типографика, контейнер, `section`, кнопки, `icon-button`, иконки | не знает о блоках страниц |
| `css/header.css` | шапка компьютера, закреплённое состояние `header--scrolled`, прозрачная шапка главной `header--overlay`; до 1024 px шапка скрыта | поиск внутри шапки рисует `search.css` |
| `css/mobile.css` | мобильная схема до 1024 px: нижняя панель `tabbar`, строка поиска сверху `quickbar`, листы `sheet` (меню, фильтры, сортировка); окна заявок `sheet--window`: с 769 px окно по центру, уже лист на весь экран | выпадашки (`picker.css`) |
| `css/hero.css` | первый экран главной: фото слоем, заголовок, вкладки стран | панель поиска |
| `css/search.css` | `finder` (вкладки стран, строка поиска и ряд фильтров одной панелью) и ряд `search`, ужатый вид для шапки | выпадашки внутри (`picker.css`) |
| `css/picker.css` | выпадающий список `picker`: на компьютере выпадает вниз, до 1024 px выезжает листом снизу | раскладку вокруг себя |
| `css/blocks.css` | `direction`, `projects`, `project-card`, `faq`, `footer`, `to-top` | формы |
| `css/form.css` | `lead-form`, `form` (модификатор `form--columns_4`), `field`, своя галочка `field__check-input`, `field-box` (поле с подписью внутри рамки) | |
| `css/catalog.css` | раскладка каталога, плавающая панель фильтров `catalog__bar`, кнопка сортировки для телефона, `chips`, `pagination`, `empty`, содержимое окна заявки `modal` | общие блоки, само окно (`sheet--window` в `mobile.css`) |
| `css/pages.css` | простые страницы: `page`, хлебные крошки `crumbs`, список с галочками `ticks`, `about`, `contacts`, документ `doc` с боковым списком `doc-nav`, `not-found` | карточку объекта |
| `css/object.css` | карточка объекта: `object`, `gallery`, `summary`, `payment`, `plans` и `plan-card`, `invest`, `sources`, объект в окне заявки `lead-object` | окно заявки рисуют `sheet--window` и `modal`, поля `form.css` |
| `js/picker.js` | подставляет выбранное в кнопку выпадашки, закрывает её после выбора, по клику мимо, крестику и Escape; на телефоне сначала уводит лист вниз | без него выпадашки тоже открываются и выбирают |
| `js/sheets.js` | открывает листы `dialog.sheet` модально по `data-sheet-open`, закрывает по крестику и затемнению, очищает строку поиска сверху | без него листы открываются ссылкой через `:target`, без анимации |
| `js/swipe.js` | закрывает свайпом вниз за ручку или заголовок лист снизу `sheet--bottom` и лист выпадашки на телефоне: лист едет за пальцем, дальше четверти высоты или резким движением закрывается, иначе возвращается | без него листы закрываются крестиком, затемнением и Escape |
| `js/header.js` | только на главной: когда первый экран (`data-first-screen`) ушёл из окна, ставит `header--scrolled` шапке и `quickbar--shown` строке поиска | без него шапка и строка остаются как в начале страницы |
| `js/to-top.js` | показывает кнопку «наверх», когда прокручен первый экран | без него кнопка не видна |
| `img/` | фото, логотип в webp | |

Правила:
- классы по БЭМ (`block__element--modifier`), цвета и размеры только через переменные;
- раскладка на flex, grid только у сеток карточек и для наложения текста на фото;
- брейкпоинты 1240, 1024, 768, 480, 400; с 1024 px и уже включается мобильная схема;
- всё работает и без скриптов: листы и окно заявки открываются через `:target`
  (`#menu`, `#filters`, `#sort`, окна заявок `#podbor-modal` и `#usloviya`, закрытие ссылкой на `#`), выпадашки сделаны на
  `<details>` с радиокнопками, фильтры отправляются обычной GET-формой, сортировка и страницы это ссылки;
- анимации листов и выпадашек на CSS (`@starting-style`, `transition-behavior: allow-discrete`): где браузер
  их не умеет, окно просто открывается сразу; при `prefers-reduced-motion` переходы выключены;
- кольцо фокуса только с клавиатуры, у полей ввода фокус показывает цвет рамки;
- в формах заявок первое поле `company_website` это приманка для ботов, скрыта за экраном классом `trap`.

На компьютере шапка закрепляется только на главной, в каталоге за прокруткой едет панель фильтров.
На телефоне и планшете шапки нет: навигация в нижней панели, поиск и кнопка «Фильтры» в строке сверху.

Пока не сделано, нужно на этапе с сервером: проверка форм и маска телефона в поле «Контакт», когда в нём
цифры, отметка кнопок «В избранное» и «К сравнению», список городов под выбранную страну, поиск по
строке «Проект, город или застройщик». В карточке объекта: просмотр фото галереи крупно, настоящие схемы
планировок (сейчас на их месте фото интерьеров) и файл презентации (ссылка пустая).

## Внешние зависимости

- Шрифт Montserrat (OFL) с Google Fonts. Если сервис недоступен, текст показывается системным шрифтом.
  Для боевого сайта шрифт лучше положить на свой сервер.
- Свайп листов свой (`js/swipe.js`, 70 строк на Pointer Events): готовые решения для листов снизу либо
  привязаны к React, либо приносят свою разметку листа и не работают с `<dialog>` и `<details>` прототипа.
- Иконки: пути из Tabler Icons 3.50.0 (MIT), вставлены спрайтом в начало каждой страницы. Иконка
  сравнения своя.
- Фото объектов и логотип взяты с сайта hotdeals.estate того же владельца. Фон первого экрана
  (`img/hero-dubai.webp`) сгенерирован нейросетью gpt-image-2.5.
